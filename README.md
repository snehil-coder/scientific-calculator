# 🧮 Scientific Calculator (Streamlit)

A simple and interactive Scientific Calculator built using **Python and Streamlit**.  
It supports basic arithmetic operations as well as scientific functions with a clean UI.

---

## 🚀 Features

- Basic arithmetic operations (+, -, *, /)
- Scientific functions:
  - sin, cos, tan
  - sqrt
  - log (base 10)
  - ln (natural log)
- Power operation using (^)
- Brackets support ( )
- Real-time expression evaluation
- Calculation history
- Clean and responsive UI using Streamlit

---

## 🛠️ Technologies Used

- Python 🐍
- Streamlit 🎈
- Math library
